# Coursework — ITS Tech Talent Factory

Exercises and exam projects from my Fullstack Software Development program at ITS Tech Talent Factory in Milan (2025–2027). 

## Frontend

- [movieapp-buzzi](https://github.com/fsda1-ITS-Tech-Talent-Factory/movieapp-buzzi): Frontend JS module final exam. A movie and TV browser on the TMDB API, in plain JavaScript with ES modules.
- [fe-buzzi](https://github.com/fsda1-ITS-Tech-Talent-Factory/fe-buzzi): exercises, frontend programming with JavaScript.
- [esercizi-frontend-buzzi](https://github.com/fsda1-ITS-Tech-Talent-Factory/esercizi-frontend-buzzi): exercises, HTML and CSS.

## DevOps

- [devstudio-corinnabuzzi](https://github.com/fsda1-ITS-Tech-Talent-Factory/devstudio-corinnabuzzi): final exam, Git & GitHub. A static site built with a documented Git workflow: feature branches, pull requests, rebase, squash merges, conflict resolution.
- [git-corinna-app](https://github.com/fsda1-ITS-Tech-Talent-Factory/git-corinna-app): exercises, Git and version control.

By [Corinna Buzzi](https://github.com/corinnabuzzi).
